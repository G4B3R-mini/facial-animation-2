# Local test subjects

Place optional models, source images and run reports here, or use `work/`.
Everything in this directory except this README is ignored. No sample models,
voice clips or generated output are distributed with the repository.

Keep reusable source tests under `tests/`; fixture-dependent personal regression
scripts and old experiment runs are local only. Record source provenance and
model-specific settings alongside the ignored fixture, and compare renders when
changing deformation behavior.
